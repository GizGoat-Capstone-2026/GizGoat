# ✨ Clean Datasets Documentation

Repositori ini memuat data yang telah melalui tahap *data preprocessing* menyeluruh dan siap digunakan untuk analisis lanjutan atau pemodelan prediktif.

---

### 🏃‍♂️ 1. `[clean]dataset_lifestyle.csv`
**Status:** 🟢 Ready for Machine Learning / Statistical Modeling

Dataset hasil pembersihan dan standardisasi ini merupakan versi matang dari data gaya hidup yang telah bebas dari **nilai kosong (*missing values*)**, **pencatatan ganda (*duplications*)**, serta **inkonsistensi penulisan kategori** pada variabel seperti profesi dan kategori BMI. 

> **Key Insight:** Dengan struktur data yang kini seragam, terindeks secara konsisten tanpa bias data eror, serta siap diintegrasikan langsung ke dalam permodelan statistik maupun algoritma pembelajaran mesin (*machine learning*), dataset ini sangat andal untuk mendeteksi korelasi presisi antara durasi tidur harian, tingkat stres, dan pola kebiasaan individu terhadap status kesehatan mereka.

---

### 🥑 2. `[clean]dataset_nutrisi.csv`
**Status:** 🟢 Ready for Quantitative Analysis / Data Visualization

Dataset ini adalah produk transformasi dari data gizi mentah yang telah melalui **konversi tipe data** dari format teks bersatuan (seperti gram) menjadi **nilai numerik murni (*float/integer*)** pada kolom kalori, lemak, karbohidrat, dan protein setelah berhasil menangani **nilai pencilan (*outliers*)**. 

> **Key Insight:** Melalui struktur data baru yang bersih dan terstandarisasi ini, variabel makronutrisi kini siap digunakan untuk analisis kuantitatif langsung, agregasi statistik, serta visualisasi distribusi gizi demi mempermudah komparasi nilai nutrisi antar menu makanan tanpa kendala ketidakcocokan tipe data.
